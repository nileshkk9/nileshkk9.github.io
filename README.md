# The Systems Architect

Interactive 3D portfolio of Nilesh Kumar Pandey. Live at [nileshkk9.github.io](https://nileshkk9.github.io/).

```bash
npm install
npm run dev
```

Pushes to `main` build a static export and deploy it to GitHub Pages. The previous site is on `backup/legacy-site` (source) and `backup/legacy-pages` (what GitHub Pages used to serve).
